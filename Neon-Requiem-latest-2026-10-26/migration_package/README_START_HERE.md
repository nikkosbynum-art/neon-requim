# Neon Requiem — Offline Codex Migration Kit
Created 2026-10-24 from verified local reconstruction archive plus connected Notion and Google Drive inventories.

## Use
1. Extract this ZIP into an empty folder or a separate `migration/` folder inside your Codex workspace.
2. In Codex: **Read AGENTS.md and README_START_HERE.md. Inspect all files, reconcile with any existing project, and implement a Godot 4 BREAKER Tier I vertical slice. Do not delete existing work.**
3. `notion_reconstruction/` contains an organized offline working reconstruction of all eight Notion pages and HQ. It is **not** a byte-for-byte Notion export.
4. `drive_assets/` contains the original files from the previously verified Google Drive reconstruction archive (four PNGs, production spec, README, MANIFEST). The Drive archive itself is not duplicated to avoid unnecessary size.
5. `docs/` records decision status, implementation status, and the Drive inventory.

## Caveats
- This is a handoff and asset/reference kit, **not a playable Godot project**.
- The four PNGs are concept sheets, not transparent rig-ready sprite parts.
- The remote Drive folder `07 — Notion Exports` was empty at inspection.
- Codex does not need Notion/Drive connections to read this package.
